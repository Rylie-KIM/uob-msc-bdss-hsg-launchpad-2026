Main Features in Mental Health Support Platform

Our platform name is Lumenia. Please use this name consistently throughout all steps.

Main Page
The main page will serve as the central hub of the platform and will include three primary buttons:

Sleeping Assistant – provides mental health support through an LLM-based conversational chatbot.
Sleep Diary – allows users to record their daily sleep patterns and receive personalized sleep predictions.
Community – provides access to the social forum where users can share experiences and support others.
Key functions of the AI Agent include:

Mental Health Support – users can talk with the AI chatbot for emotional support and guidance.
RAG-based CBT-i Support – the chatbot uses Retrieval-Augmented Generation (RAG) with Cognitive Behavioral Therapy for Insomnia (CBT-i) resources to provide evidence-based suggestions for improving sleep and mental wellbeing.

Daily Sleep Pattern Prediction (Personalization)
The platform provides personalised sleep insights using machine learning and LLM analysis.

Main components include:

Sleep Diary Input
Users record their daily sleep information, including:
Time they go to sleep
Time they wake up
The data will be stored in a SQL database.
ML Backend Prediction
A machine learning model analyzes the collected sleep diary data.
The system predicts users’ sleep patterns and trends.
LLM Agent Analysis
The LLM agent interprets the predictions and provides understandable feedback and recommendations.
Dynamic Updates
Predictions are updated whenever new sleep diary entries are submitted.
Social Page (Community)
The platform includes a judgment-free community space where users can connect and support each other.

Features include:

Forum-style discussion
Posts – users can share their experiences, stories, or challenges.
Comments – users can reply, give advice, or offer encouragement.
For the demo version, external APIs are not required.
